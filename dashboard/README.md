# DevOps Digital Twin Dashboard

Phase 23 establishes the React and TypeScript dashboard foundation for the DevOps Digital Twin project. The current screen uses static placeholder data; backend API integration is intentionally deferred to a later phase.

## Technologies

- React
- TypeScript
- Vite
- CSS

## Installation

From this directory:

```bash
npm install
```

## Development

```bash
npm run dev
```

Open the development dashboard at http://localhost:5173.

## Production build

```bash
npm run build
```
