# DevOps Digital Twin

A DevOps-focused Digital Twin system for infrastructure simulation,
what-if analysis, resource prediction, failure simulation, and
deployment impact analysis.

## Project Objective

The system creates a software-based Digital Twin of a
cloud-native DevOps environment and uses it to simulate
different infrastructure scenarios before performing
controlled experiments on the real environment.
